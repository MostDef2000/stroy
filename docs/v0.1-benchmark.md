## Acceptance Evidence

- [ ] **Anonymous rejection**: Curl without token → 401.
  - *Verification*: Execute `curl` against API endpoints without `Authorization` header.
- [ ] **Home worker offline → jobs visibly wait**:
  - *Verification*: Stop local worker, submit job, verify `waiting_for_worker` status in API.
- [ ] **Provenance tracking**:
  - *Verification*: Check `adapter_provenance` in style profiles, `GenerationManifestRow` for generations, and ComfyUI server version.
- [ ] **Geometry diagnostics**:
  - *Verification*: VPS worker now uses `GeometryQualityExecutor` (real) instead of `FakeExecutor`.
- [ ] **Canonical Scene**:
  - *Verification*: Load fixtures/golden-room.scene.json and verify consistency.
- [ ] **Camera calibration**:
  - *Verification*: Verify projection matrices match fixtures/golden-camera.correspondences.json.
- [ ] **Style profiling**:
  - *Verification*: Verify Qwen-VL correctly identifies materials/styles from reference images.
- [ ] **Geometry locking**:
  - *Verification*: Verify redesign jobs do not mutate locked geometry attributes.
- [ ] **Text-based editing**:
  - *Verification*: Verify prompt-based material/color changes in generated outputs.
- [ ] **Furniture replacement**:
  - *Verification*: Verify reference-image guided object replacement.
- [ ] **Revision history**:
  - *Verification*: Verify undo/redo of design commands via API.

## Known Limitations / Next Priorities

- **Generation conditioning**: Currently based on prompt+seed only; geometry/style conditioning descoped from the first workflow (see #13).
- **Blender Rendering**: `render.blender` executes as a fake stub on the VPS worker (no Blender binary present; rendering is a home-workstation capability).
- **Ollama Context**: Ollama on the PC uses context wrappers (qwen3-vl-16k) because default context is too large; `think:false` requires an ollama upgrade.
- **System Updates**: 64 apt packages on the box await root updates.
